Each gotcha is one page on the same template: the **symptom** as it first
shows on the bench or in a design, **why** it happens, **how to confirm**
that this is the cause and not another with the same symptom, the **fix**,
and the **references** behind every claim. The tags group them; a page's
tags link back to the lists below.

<GotchaIndex part="list" />

To write up a mistake of your own, start from the
[gotcha page template](https://github.com/Denny-Hwang/switching_converter_study/blob/main/docs/GOTCHA_TEMPLATE.md).
