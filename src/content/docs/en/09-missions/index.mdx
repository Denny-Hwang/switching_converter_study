A mission is a small project: it names what to build or find, links the page
and the tool to use, and ends with acceptance criteria that say when it is
done. Some criteria ask for a number and check it against a synthetic
example's value; the others you tick off yourself. The missions build on each
other from M1 to M8, and M9 asks you to write a page for this site.

Your ticks are kept in this browser only, in its local storage. There is no
account, nothing is sent anywhere, and clearing the browser's site data clears
them. The same missions in the other language share the ticks.
