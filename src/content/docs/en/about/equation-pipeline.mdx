This page exercises the chain that every later page depends on:

1. `packages/pe-core/equations/equations.yaml` holds the expression, its
   assumptions, its citation and hand-checked test values.
2. `python scripts/gen_equations.py` parses it with sympy, generates the
   LaTeX and the shared test vectors, and fails if a test value disagrees
   with the expression.
3. The TypeScript engine is tested against those vectors (1e-9 relative),
   and every generated formula is rendered by KaTeX in strict mode.
4. The docs embed the result with `<Eq id="…" />`; nobody types LaTeX.
