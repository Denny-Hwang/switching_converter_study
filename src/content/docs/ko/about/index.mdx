전기공학 엔지니어를 위한 전력전자 공개 학습 저장소입니다. 스위칭 컨버터
이론(CCM/DCM), 토폴로지, 자성 부품, 손실 모델링, 에너지 하베스팅
인터페이스를 다루며, 계산기와 브라우저 기반 컨버터 시뮬레이터를 함께
제공합니다.

## 원칙

- **처음부터 끝까지 검증 가능.** 모든 수식은
  `packages/pe-core/equations/equations.yaml` 한 곳에만 존재합니다. LaTeX는
  자동 생성되고, 유도 과정(derivation)은 sympy로 재현되며, 도구를 구동하는 TypeScript
  엔진은 공유 테스트 벡터에서 Python 기준 구현과 상대오차 1e-9 이내로
  일치해야 합니다.
- **인용.** 모든 수식과 소자·방법에 대한 주장은 `references.bib`의 키를
  갖습니다. 아직 검증되지 않은 항목은 공개 페이지에서 인용할 수 없습니다.
- **자동 점검.** 수식은 KaTeX 엄격 모드(strict mode)로 렌더링되고, 빌드된
  사이트의 링크를 검사하며, CI에서 개인정보 스캔을 수행합니다.
- **비공개 데이터는 비공개로.** 실제 프로젝트의 측정 데이터, 식별자, 설계
  선택값은 사용하지 않습니다. 수치는 인용한 교과서 예제의 값이거나, 실제
  설계의 데이터가 공개되지 않도록 교육용으로 만든 합성(synthetic) 어림수입니다.
  모든 페이지의 바닥글(footer)도 이를 밝힙니다. 저장소의 `PRIVACY_RULES.md`를
  참고하세요.
- **이중 언어.** 영어가 원본(canonical)이며, 한국어는 같은 페이지를
  그대로 옮긴 미러입니다.

## 로드맵

| 단계 | 범위 |
| --- | --- |
| 0 | 사이트 골격, CI, 배포, 수식 파이프라인 뼈대 |
| 1 | 수식 엔진: 전체 기본 수식 세트, 유도, 패리티 테스트 |
| 2 | 핵심 콘텐츠: 이론과 주요 토폴로지 (영어 후 한국어) |
| 3 | 시간 영역 시뮬레이터와 설계 도구 |
| 4 | 자성 부품, 벤치 실무, 에너지 하베스팅, 흔한 함정(gotchas), 자료 모음 |
| 5 | LTspice/ngspice/CircuitJS 라이브러리, 미션, 릴리스 |
