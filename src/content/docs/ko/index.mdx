import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid>
  <Card title="학습 (Learn)" icon="open-book">
    전압-초 평형(volt-second balance)에서 CCM/DCM, 토폴로지, 자성 부품(magnetics),
    손실, 에너지 하베스팅 인터페이스까지 이론을 다룹니다. 모든 수식은 하나의 원본
    파일에서 생성하고 테스트로 검증합니다.
  </Card>
  <Card title="설계 (Design)" icon="setting">
    컨버터, 자성 부품, 손실 예산(loss budget), 전류 센싱 체인, 클램프를 위한
    계산기입니다. 모두 테스트를 거친 같은 수식 엔진으로 계산합니다.
  </Card>
  <Card title="시뮬레이션 (Simulate)" icon="rocket">
    브라우저에서 실행되는 시간 영역(time-domain) 컨버터 시뮬레이터와, 모든
    토폴로지의 LTspice·ngspice·CircuitJS 파일을 제공합니다.
  </Card>
  <Card title="검증 (Verify)" icon="approve-check">
    유도 과정(derivation)은 sympy로 재현합니다. TypeScript와 Python 구현은
    1e-9까지 일치하며, 인용과 링크는 CI에서 검사합니다.
  </Card>
</CardGrid>

벤치와 설계에서 되풀이되는 실수는 증상, 원인, 해결과 함께
[주의할 점](08-gotchas/)에 모았습니다.

이 사이트는 단계적으로 구축되고 있습니다. 원칙과 로드맵은 [소개](about/)를,
모든 페이지의 기반이 되는 검증 체인은 [수식 파이프라인 점검](about/equation-pipeline/)을
참고하십시오.
