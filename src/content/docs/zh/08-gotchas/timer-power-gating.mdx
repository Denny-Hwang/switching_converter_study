## 现象

由毫微功耗定时器（nano-power timer）通断电源的负载（定时器每隔一段时间接通一个电源开关，并在负载发出已完成的信号时再将其断开）刚启动就被关断，或只运行一次，或在不同电路板上表现各不相同。

## 原因

这类定时器（例如 TPL5110 <Cite key="ti_tpl5110" />）有两个输入很容易处于未定义状态：

- 其 EN/ONE_SHOT 引脚用于在周期工作和单周期工作之间选择，必须用短走线接到 GND 或 VDD <Cite key="ti_tpl5110" />。悬空引脚的电平不确定，工作模式也就不确定。
- 其 DONE 输入是负载表示已完成的信号。定时器把由低到高的跳变当作有效的 DONE 并关断负载，短至 100 ns 的脉冲就已足够 <Cite key="ti_tpl5110" />。持续这么长时间的非预期上升沿会像真正的 DONE 一样结束本周期：例如在控制器启动、其固件尚未驱动某个引脚时，来自该引脚的上升沿。

## 如何确认

在负载上电期间用示波器观察 DONE，以上升沿触发，时基要足够短，能显示数据手册规定的最小宽度的脉冲。若在固件发出已完成信号之前 DONE 上就出现脉冲，这就是原因。检查模式引脚是否直接连到 GND 或 VDD。

## 解决方法

用短走线把模式引脚接到 GND 或 VDD <Cite key="ti_tpl5110" />。由于 DONE 上的上升沿会结束本周期 <Cite key="ti_tpl5110" />，应用下拉电阻把 DONE 拉低，使其在无驱动时保持低电平，并让固件只在工作完成后才将其拉高。然后重复上面的检查。
