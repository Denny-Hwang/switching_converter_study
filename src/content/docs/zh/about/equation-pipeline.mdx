本页检验后续所有页面都依赖的这条链路：

1. `packages/pe-core/equations/equations.yaml` 保存公式表达式、其假设、引用和手工核对过的测试值。
2. `python scripts/gen_equations.py` 用 sympy 解析该文件，生成 LaTeX 和共享测试向量；若有测试值与表达式不符，则运行失败。
3. TypeScript 引擎用这些向量测试（相对误差 1e-9），每个生成的公式都由 KaTeX 以严格模式（strict mode）渲染。
4. 文档用 `<Eq id="…" />` 嵌入结果；不手工输入任何 LaTeX。
