这是一个面向电气工程师的开放式电力电子学习资源库：开关变换器理论（CCM/DCM）、拓扑、磁性元件、损耗建模和能量收集接口，并配有计算器和在浏览器中运行的变换器仿真器。

## 原则

- **端到端可验证**。每个公式只在 `packages/pe-core/equations/equations.yaml` 中出现一次。其 LaTeX 由程序生成，其推导（derivation）在 sympy 中复现，驱动各工具的 TypeScript 引擎必须在共享测试向量上与 Python 参考实现一致，相对误差在 1e-9 以内。
- **注明出处**。每个公式以及每条关于器件或方法的论断都带有 `references.bib` 中的引用键。尚未核实的条目不能在已发布的页面上引用。
- **自动检查**。数学公式用 KaTeX 以严格模式（strict mode）渲染，链接在构建好的站点上检查，CI 中还运行隐私扫描。
- **私有数据不公开**。不使用任何真实项目的测量数据、标识信息或选型参数。数值或取自所引用的教科书例题，或为合成（synthetic）的取整教学用数值。每个页面的页脚（footer）都重申这一点。参见仓库中的 `PRIVACY_RULES.md`。
- **多语言**。以英文为准（canonical）；韩文和中文是同一套页面的镜像。
